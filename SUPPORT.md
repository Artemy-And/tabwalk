# Getting help

- **How do I…? / Is this expected?** Ask in [Discussions → Q&A](https://github.com/Artemy-And/tabwalk/discussions/categories/q-a).
  Search first — someone may have asked already.
- **Something is broken.** Open a [bug report](https://github.com/Artemy-And/tabwalk/issues/new?template=bug_report.yml)
  with your version, how you run Tabwalk and the logs.
- **A security vulnerability.** Report it privately, see [SECURITY.md](SECURITY.md).

Tabwalk is maintained in spare time. Questions are usually answered within a few days. Answers go
in public threads so the next person with the same question finds them too.
